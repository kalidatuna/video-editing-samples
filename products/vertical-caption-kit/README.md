## What the package contains

- Three `.ass` files with editable timing, text, size, color and outline.
- A usage guide for ASS-compatible software and FFmpeg/libass.
- A buyer license permitting personal and commercial video use and modification, excluding standalone redistribution or resale.

All three styles have been test-rendered. Fonts, footage, music and Adobe preset files are not included.
